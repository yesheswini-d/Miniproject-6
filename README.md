# 🏦 Loan Approval Prediction Using Machine Learning

## Project Description

Loan Approval Prediction is a Machine Learning project that predicts whether a loan application is likely to be approved or not.

The project uses applicant information such as income, education, credit history, loan amount and property area.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Logistic Regression
- Pickle

## Machine Learning Algorithm

Logistic Regression is used because loan approval is a binary classification problem.

Output:

1 = Loan Approved

0 = Loan Not Approved

## Features

The model uses:

- Gender
- Married
- Education
- Self Employed
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Term
- Credit History
- Property Area
